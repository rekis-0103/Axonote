# API Contract

Base path: `/api/v1`. All bodies JSON unless noted. Auth via `Authorization: Bearer <access_token>`.

Interactive/OpenAPI: `http://localhost:8000/docs` (generated by FastAPI — canonical source).

## Conventions

- Timestamps: ISO-8601 UTC.
- Errors: `{ "detail": "<message>", "code": "<machine_code>" }`. No stack traces, SQL, or paths leaked.
- Pagination: `?limit=20&offset=0` where applicable.
- Ownership: 404 (not 403) when accessing another user's resource, to avoid existence leaks.

## Auth

### POST /auth/register
Req: `{ "email": string, "password": string, "display_name": string }`
Res `201`: `{ "access_token": string, "refresh_token": string, "token_type": "bearer", "user": { "id", "name", "email" } }`

### POST /auth/login
Req: `{ "email": string, "password": string }`
Res `200`: `{ "access_token": string, "refresh_token": string, "token_type": "bearer" }`
Rate-limited.

### POST /auth/google
Req: `{ "credential": string }` — Google Identity Services ID token from the frontend.
Res `200`: `{ "access_token": string, "refresh_token": string, "token_type": "bearer", "user": { "id", "name", "email" } }`
Server verifies audience, issuer, expiry, and `email_verified` before issuing an Axonote JWT.
Rate-limited.

### POST /auth/refresh
Req: `{ "refresh_token": string }`
Res `200`: `{ "access_token", "refresh_token" }` (rotates refresh token)

### POST /auth/logout
Req: `{ "refresh_token": string }` → revokes it. Res `204`.

### GET /auth/me
Res `200`: `{ "id", "email", "display_name", "role" }`

## Materials

### POST /materials
`multipart/form-data`: `file` (pdf/docx/pptx, ≤20 MB), optional `title`.
Validated: extension, size, MIME + magic bytes. Stored with random name.
Res `201`: `{ "id", "title", "original_name", "status": "pending", "created_at" }`
Rate-limited.

### GET /materials
Res `200`: `{ "items": [ { "id", "title", "status", "created_at" } ], "total" }`
Only the caller's materials.

### GET /materials/{id}
Res `200`: `{ "id", "title", "original_name", "mime_type", "size_bytes", "status", "error_message", "created_at" }`

### POST /materials/{id}/analyze
Creates an analysis job (idempotent: returns existing active job if present).
Res `202`: `{ "job_id", "status": "queued" }`

### GET /materials/{id}/jobs/latest
Returns the most recent analyze job for the material (any status).
`404` if no job exists. Res `200`: same shape as `GET /jobs/{id}`.

### GET /materials/{id}/summary
`404` if not ready. Res `200`: `{ "material_id", "content", "keywords": [string], "created_at" }`

## Jobs

### GET /jobs/{id}
Res `200`: `{ "id", "material_id", "type", "status", "error_message", "created_at", "finished_at" }`
Web polls this until `done` / `failed`.

## Quiz

### GET /materials/{id}/question-set
Res `200`: `{ "question_set_id", "questions": [ { "id", "type", "stem", "options": [string] } ] }`
**`correct_index` and `explanation` are omitted** until an attempt is submitted.

### POST /question-sets/{id}/attempts
Req: `{ "answers": [ { "question_id": number, "chosen_index": number } ] }`
Res `201`:
```json
{
  "attempt_id": 1,
  "score": 7,
  "total": 10,
  "results": [
    { "question_id": 1, "chosen_index": 2, "correct_index": 0, "is_correct": false, "explanation": "..." }
  ]
}
```

### GET /question-sets/{id}/attempts
Caller's attempt history. Res `200`: `{ "items": [ { "attempt_id", "score", "total", "started_at", "finished_at" } ] }`

## Status enums

- `material.status`: `pending | processing | ready | failed`
- `job.status`: `queued | running | done | failed`
